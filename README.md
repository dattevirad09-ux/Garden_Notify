# 我的菜园 🌱

一个纯静态、可安装为手机 PWA 的菜园记录网页。记录南瓜、茄子、西瓜等作物的生长阶段、浇水/施肥周期，带日夜循环的可视化田地。

## 关于隐私
所有数据（植株、日期、浇水施肥记录）只保存在 **你自己浏览器的 localStorage** 里，代码里没有任何服务器、数据库或网络请求会发送你的数据。即使把这个网页部署在公开的 GitHub Pages 上：

- 任何人打开这个网址，看到的都是**他们自己浏览器里的空数据**，不会看到你的记录；
- 你的数据不会跨设备同步（这既是隐私优点，也意味着换设备/清浏览器数据前要记得在"设定"页导出备份 JSON）。

如果不放心，也可以把仓库设为 GitHub 的 Private 仓库 + Pages（需要 Pro 账号），或部署到自己的服务器/内网。

## 部署到 GitHub Pages
1. 新建一个仓库（比如 `my-garden`），把本文件夹里的所有文件（`index.html`、`manifest.json`、`sw.js`、`icons/` 整个文件夹）上传到仓库根目录。
2. 进入仓库 **Settings → Pages**，Source 选择 `main` 分支 / `root` 目录，保存。
3. 等一两分钟，访问 `https://你的用户名.github.io/my-garden/` 即可。
4. 手机浏览器打开网址后，选择"添加到主屏幕"（iOS Safari）或"安装应用"（Android Chrome），就能像 App 一样使用，支持离线打开。

## 文件说明
- `index.html` — 页面主体，包含全部样式与逻辑
- `manifest.json` — PWA 配置（图标、启动方式）
- `sw.js` — Service Worker，用于离线缓存
- `icons/` — 应用图标

## 主要功能
- **花园**：日夜循环的泥地场景，已种下的作物按种类和生长阶段显示对应插画；有浇水/施肥待办时会出现提醒角标和待办列表
- **创建**：预设南瓜🎃、茄子🍆、西瓜🍉、番茄🍅、辣椒🌶️、黄瓜🥒（也可选"自定义🌿"），可设置种植日期、浇水/施肥周期，也可手动指定当前阶段（比如你买回来的苗已经是幼苗期）
- **日历**：按月查看历史浇水💧/施肥🌰/收获🧺记录，点开某一天看当天详情
- **详情弹层**：点击花园里的作物图标，可"打卡"浇水/施肥、记录收获、编辑周期与阶段、删除植株
- **设定**：修改花园名称、切换白天/黑夜/自动主题、导出导入备份 JSON、清空数据

## 关于提醒的局限
纯静态网页没有后台服务，无法像原生 App 一样主动推送通知。建议把网页加到手机主屏幕，养成每天打开看一眼"今日待办"的习惯。
